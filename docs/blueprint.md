# **App Name**: Harsh Singh Portfolio

## Core Features:

- Hero Section: Dynamic introduction section with name, role (Data Analyst / Aspiring Data Scientist), and concise value proposition to capture visitor attention.
- Skills Showcase: Categorized display of technical skills: Excel, SQL, Python, Power Query, Power Pivot, Data Visualization, ETL, Dashboards. Provides clear evidence of expertise.
- Interactive Project Portfolio: Detailed project breakdowns, including title, problem statement, tools used, and quantifiable key outcomes, showcasing practical experience and results.
- Resume Optimizer: Use an AI tool to check your resume for key data science terms, skills, and length. If content or formatting updates would make the resume stronger, the LLM should recommend specific improvements. Make your resume sparkle!
- Experience Timeline: Chronological presentation of professional experience, education, and certifications to build credibility and highlight career progression.
- Contact Gateway: Direct links to professional contact points, including Email, LinkedIn, and GitHub, simplifying communication for recruiters and hiring managers.

## Style Guidelines:

- Primary color: Slate Blue (#708090) to convey professionalism and stability.
- Background color: Off-White (#F5F5F5) for a clean, distraction-free backdrop.
- Accent color: Teal (#008080) to highlight key elements and calls to action, promoting engagement.
- Body and headline font: 'Inter', a grotesque-style sans-serif, will be used for headlines and body text.
- Clean, minimalist design with ample white space for readability. Intuitive navigation and clear section breaks.
- Subtle scroll animations and transitions to enhance user experience without overwhelming the user.
- Use professional, consistent icons for skills and contact information, ensuring visual appeal and ease of understanding.
